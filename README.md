# simple-cloud-disk-team
简易云盘团队协作项目，基于Python+Flask开发，实现用户认证、文件管理、前端交互、自动化测试部署全功能。
## 团队分工
- 组长：仓库初始化、分支管理、代码合并、项目统筹
- 成员A：user-auth-module分支 → 用户注册/登录/权限校验模块
- 成员B：file-hadoop-module分支 → 文件上传/下载/预览/目录隔离模块
- 成员C：frontend-module分支 → 前端静态页面/表单校验模块
- 成员D：test-deploy-module分支 → 自动化测试/项目部署/测试报告模块
## 技术栈
Python3 + Flask + JSON + 原生HTML/CSS/JS + Shell脚本
